# Guru99 Banking Project - Manual Testing

## Project Overview
This project involves manual testing of the **Guru99 Bank** demo application. The objective is to validate key banking functionalities and ensure the application works as expected. The testing approach includes various manual test cases covering login, customer management, transactions, and more.

🔗 Application URL: [http://demo.guru99.com/V4/](http://demo.guru99.com/V4/)

## Features Tested
- **User Authentication**
  - Login functionality (valid and invalid credentials)
  - Session management

- **Customer Module**
  - Add new customer
  - Edit customer details
  - Delete customer

- **Account Module**
  - Create new account
  - Edit account details
  - Delete account

- **Logout functionality**

## Tools & Technologies Used
- Manual Testing
- Test Case Writing (Excel or Google Sheets)
- Bug Reporting (JIRA or Excel)
- SDLC/STLC knowledge
- Black Box Testing
- ISTQB techniques like Boundary Value Analysis, Equivalence Partitioning
